# Papers

## Primary paper

- Arreche, O., Guntur, T., and Abdallah, M. (2024). *XAI-IDS: Toward Proposing an Explainable Artificial Intelligence Framework for Enhancing Network Intrusion Detection Systems*. Applied Sciences, 14(10), 4170.
- DOI: https://doi.org/10.3390/app14104170
- Article: https://doi.org/10.3390/app14104170

The paper benchmarks seven black-box models on CICIDS-2017, NSL-KDD, and RoEduNet-SIMARGL2021, then produces local and global explanations with SHAP and LIME. The publisher's article is linked above; copyrighted article files are not stored in this repository.
